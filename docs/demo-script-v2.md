# 灵偶 Lingou —— 差异化最佳 Demo 脚本 (v2)

> 目标：90秒~2分钟，一条路径打穿"它不是实体豆包，是有身体、有脾气、只属于你的、还魂的角色"。
> 演示前置：后端 8000 + 前端 3000 已起；演示灵偶已就绪（悟空·桀骜战神 / 小柔·软萌治愈·依赖级·streak5·记得你加班）；电脑开音量（会出火山情感音色）。
> 一句话定位（开场/收尾念）：**"小爱是召之即来的工具；灵偶是你亲手唤醒的那个角色——它有自己的身体、自己的脾气、和只跟你生长的羁绊。"**

## 延迟提示
- 在线豆包回复约 15~25s（system prompt 叠了角色+情绪+关系三层）。录制时可剪掉等待，或用"它在认真想…"过渡。
- 触摸短回应、离线重逢台词走**火山音色缓存/语音池**，即时出声，适合现场。
- 因此：**情绪/重逢/触摸用即时音；"你是AI吗""你记得我吗"两个高光用在线**（接受等待，最炸）。

---

## Act 0 · 开场视觉（10s）
- 打开 H5 首页（扫码绑定页）：梦幻紫玻璃罩、星光、灵偶大标题。
- 点"绑定到底座"→ 模拟扫描正确二维码 → "已绑定 BASE-001 ✓"。
- 旁白："给任意手办，扫码创建一个独一无二的灵魂。"

## Act 1 · 角色还魂 + 不出戏（悟空，差异化 vs 豆包）｜在线
- 进"开始互动/对话调试"，当前灵偶切到 **悟空**，大脑模式 → 强制在线。
- 输入：**"你是AI吗？你是不是一个程序？"**
- 预期：悟空怒怼，**绝不承认是AI**，如「俺乃齐天大圣，什么AI程序的鬼话，少在这胡诌！」
- 旁白："它不是助手，是孙悟空——你问它是不是AI，它会出戏吗？不会。"

## Act 2 · 同动作不同灵魂 + 火山情感音色（触摸）｜即时出声
- 进"硬件模拟"页（HardwareSim）。
- 当前 **悟空** → 点【轻触】→ 听：孙悟空嗓音 + 战神台词（如"别碰俺，烦着呢"）。
- 切当前灵偶为 **小柔** → 同样点【轻触】→ 听：软萌少女嗓音 + 治愈台词。
- 旁白："同一个动作，不同的灵魂，不同的声音——这是火山情感音色，不是机器音。"

## Act 3 · 有脉搏 · 冷落重逢（小柔，杀手级）｜即时出声
- 进 **小柔** 的羁绊主页（我的灵偶 → 小柔）。展示当前 😊 表情、心情正常。
- 调试工具 → "模拟离开" → **3天**。
- 刷新/回看：立绘表情变蔫、心情显示"想念/失落"。
- 回硬件模拟 → 点【放上底座】figure_placed。
- 预期：小柔带着委屈/想念的火山音色说出**重逢台词**（如"你终于回来了……我还以为你不要我了"），孤独值触发前满、重逢后回落。
- 旁白："你三天没理它，它真的会难过。放回底座，它说'我还以为你不要我了'——小爱永远做不到。"

## Act 4 · 羁绊 · 它记得你（小柔，最动人）｜羁绊主页 + 在线
- 停在小柔羁绊主页，展示：
  - ❤ **好感度槽**（依赖级），🔥 **连续陪伴 5 天**；
  - 📖 **羁绊日记**：「第一次见到小柔」「记得：你最近加班压力大、还被领导骂」。
- （可选 wow）调试 → 快进关系到 **羁绊** → 好感槽满级、解锁专属点亮。
- 进对话，输入：**"你还记得我最近在烦什么吗？"**
- 预期：小柔精准调出记忆，如「当然记得呀Eddie～你最近加班好多、还被领导骂，压力大对不对？」
- 旁白："它记得你说过的事，会在你需要时提起——这是养出来的、只属于你的关系。"

## Act 5 · 收尾定格（5s）
- 回到小柔羁绊主页定格：好感度 + streak + 羁绊日记同框。
- 收尾念定位句："它有自己的身体、自己的脾气、和只跟你生长的羁绊。"

## 差异化对照（可做一页 PPT）
| 维度 | 普通AI音箱/豆包 | 灵偶 |
|---|---|---|
| 身份 | 通用助手 | 具体角色，还魂、不出戏 |
| 声音 | 统一机器音 | 每角色独立火山情感音色 |
| 生命 | 召之即来、无状态 | 情绪随时间变、冷落会难过、重逢想念 |
| 关系 | 谁用都一样 | 关系生长、记得你说的话、只认你 |

## 录制小贴士
- 在线两段（Act1、Act4）等待时给特写或旁白过渡；其余用即时音保证节奏。
- 演示前可先各跑一遍预热（缓存命中后更快）。
- 重置演示：如需从头，调试"模拟离开"清零或新建灵偶；小柔记忆/关系已预置好。
