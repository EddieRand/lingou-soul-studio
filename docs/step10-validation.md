# 第 10 步实施与验证报告

日期：2026-09-15。

结论：第 10 步“缩短普通用户路径”在本步约定范围内验证通过。
第 11 步未开始，等待用户单独批准。

## 范围

- 普通用户只面对一个当前灵偶和一个继续交流入口。
- 首次创建只要求名字和一句话设定，其他字段使用稳定默认值。
- 创建草稿和幂等请求 ID 可跨刷新、关闭和重新打开恢复。
- 次日返回直接恢复当前角色、确认记忆和最近对话。
- 多角色收藏、模拟器、养成快进、脑模式、克隆和触摸台词退出正常路径。
- 不修改第 11 步的独立设备音频输入输出协议。

## 主路径

首次使用：

`登录 -> 单屏引导 -> 真实绑定 -> 名字 + 一句话 -> 创建并激活 -> 交流`

已有角色再次打开：

`登录 -> 当前灵偶主页 -> 继续交流`

主页不再渲染角色队伍、切换“出战”、新建角色、模拟触摸或调试对话。底部导航只保留
“当前灵偶”和“继续交流”。

若历史账号已有角色但底座缺少当前角色，主页会将第一条既有角色恢复为当前角色；正常页面不再
提供多角色切换。直接访问 `/create` 时，如已存在当前角色会返回主页。

## 最少创建与草稿

创建页不再执行图片上传、70 秒角色档案生成、灵魂契约、触摸台词和完整音色筛选。
用户只需填写：

- 名字。
- 一句话设定。

后端已有角色模板补齐人格及默认声线。创建请求仍携带 `creation_request_id` 与
`activate_base_id`，创建和底座激活保持同一可恢复事务。

草稿使用 `lingou_create_draft_v1:{user_id}` 按账号存储：

- 保存名字、一句话设定和稳定幂等 ID。
- 刷新或关闭浏览器后恢复。
- 损坏或版本不兼容的草稿安全忽略。
- 创建成功后删除；其他账号无法读到该草稿。

## 次日继续

主页显示当前角色、一句话设定、最近一条确认记忆和明确的“继续交流”按钮。
交流页首次打开时读取最近 6 个完整轮次，后续轮询不会覆盖当前会话中的流式消息。
创建成功直接进入带明确 `figure_id` 的 `/conversation`；若 URL 与底座当前角色不一致，
返回主页重新解析当前角色。

## 后置功能

正常前端路径已移除：

- 硬件模拟器与浏览器模拟事件。
- 关系快进、模拟离开、等级、streak 和冷落状态。
- 多角色列表及切换。
- 脑模式和 API 状态面板。
- 完整音色实验室、声音克隆和触摸台词编辑。

保留的后端实现仅用于未来或本地调试。下列写入口默认返回 `404`，只有
`LINGOU_ENABLE_DEV_TOOLS=1` 时可用：

- 模拟离开与关系快进。
- 浏览器事件与硬件模拟。
- 强制脑模式。
- 音色上传、克隆启动/状态和系统声线枚举。

关系等级、streak、冷落、重逢和触摸递进默认不再运行。物理触摸仍保留基础台词、灯效以及
最后交互时间；旧演示规则只能通过 `LINGOU_ENABLE_DEFERRED_GAMEPLAY=1` 显式恢复。
历史数据和模块未删除。

## 浏览器验证

使用预置虚构底座、独立账号和临时数据，在 390x844 Chrome 中完成：

1. 登录后进入单屏引导。
2. 粘贴真实配对二维码并绑定。
3. 在两字段创建页填写名字和一句话。
4. 刷新页面，草稿及幂等 ID 恢复。
5. 创建并激活，直接进入交流页。
6. 写入一条确认记忆和一轮历史对话。
7. 新浏览器上下文仅恢复登录凭据，应用自动跳过重复引导并进入当前灵偶主页。
8. 主页显示当前角色及确认记忆，点击“继续交流”恢复历史对话。
9. 直接访问 `/create`、`/simulate` 均返回当前灵偶主页；关系快进 API 返回 `404`。

主页和交流页无水平溢出、无控制台错误；交流输入框滚动后可点击且未被底部导航遮挡。
验证结束后关闭服务、移除临时 Playwright 依赖并删除临时数据。
